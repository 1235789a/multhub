# Blog CMS System

This directory manages the blog content in a git-friendly way.

## Structure

```
cms/
├── content/          # Store Markdown files here
└── index.ts          # Auto-generated file (DO NOT EDIT)
```

## Usage

1. Add or edit Markdown files in `content/` directory
2. Run `npm run build:blog` to regenerate the `blog.ts` index
3. Commit and push changes
