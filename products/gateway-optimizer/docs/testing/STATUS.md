# Beta 验收与残留项

核验日期：2026-10-22（北京时间）。总状态 **PARTIAL**：本地分析产品可运行，不代表全部生产与平台验收已完成。

## DONE — 已实现且实际验证

- 审计 GitHub/Drive 相关资产与四个上游的主分支、release与许可证；原始许可证与SHA已保留。没有复制生产报价库和私有客户数据。
- Pro与Personal独立入口、共享数据契约、费用/用量/健康/报表引擎、预算提醒、路由建议、Mock评测、CSV显式映射导入。
- USD/CNY/EUR报价与快照FX；输入/输出/缓存独立计价；实账/估算/收入/配对毛利分离；覆盖率、未知值和模拟证据明确显示。
- 186项Vitest单元/集成测试通过，包含128组确定性用量/价格向量；schema、价格历史、FX、幂等冲突、权限、租户隔离、私网URL、凭据样式拒绝和静态路径绕过检查。
- 100并发真实HTTP请求通过（至少50正常SSE流，另含429、5xx、超时、网络错误、输出后中断）；这是Mock处理器测试，不是实际模型容量承诺。耗时157ms仅反映当前短延时Mock环境。
- 4个独立进程对同一SQLite执行200次相同事件写入，新增1条记录。
- 5项Playwright E2E通过：两个产品桌面/手机流程、预算、Mock评测、已输出流禁止切换、日月周期、CSV重复导入、诊断下载、备份、删除和恢复。Chromium153 Linux headless；浏览器默认CDN下载失败，使用可获取的npm测试二进制。
- 空安装目录 npm ci --offline、编译、自动schema创建、240条样本种子、备份、移除数据库、恢复与再次备份完全一致。此处复用npm缓存，不声称无网从零下载；宿主Linux依赖仍共享。
- npm audit --omit=dev 最终报告0条已知漏洞。首次发现@fastify/static高风险路径问题和csv-parse中风险问题，升级至10.1.7/7.0.3后回归通过。该结果不等于无漏洞或完整渗透测试。
- 真正运行后的PNG与WebM/MP4录屏在evidence；完整Prompt/响应/API Key未被采集。
- 两份原创教程、安装/升级/Windows排错说明、两套与Beta实际范围一致的闲鱼草稿与交付清单。

## PARTIAL — 已有实现但验证或范围不足

- LiteLLM：模型清单适配器与部署草案已实现；没有真实供应商连接结果，没有自动在线费用采集。通过受鉴权的规范化usage API可接自己的集成，但尚未交付完整CustomLogger采集插件。
- New API：当前源码路由/权限/HTTP NDJSON格式已核对；CSV映射用合成样本测试。没有真实用户站点、真实导出文件的端到端验证，不宣称所有版本一键兼容。
- 租户隔离：服务端token/角色隔离通过；不是SaaS账户、组织权限、RLS或同机管理员隔离。
- 备份/回滚：同版本清空重建恢复通过；跨版本数据库迁移/回滚没测。删除是逻辑删除，不是取证级擦除。
- Docker/可选LiteLLM+Postgres：配置文件已写，未启动。核心本次为SQLite，没有PostgreSQL/Prisma仓储。
- 闲鱼：官方卖家/买家保障/软件协议已查；具体类目、账号权限、禁售清单及上架当天规则未全部确认，草稿未发布。
- 本仓库父站隔离：仅在PR新增独立目录；为避免父站**/*.ts与ESLint扫描子项目，两个父配置增加精确exclude/ignore。父站完整构建未运行，主分支未改、未合并、未部署。

## BLOCKED — 当前外部条件

没有真实授权API凭据与付费调用批准；没有Windows环境；没有Docker可执行文件。没有为此停止本地Mock开发，也没有购买服务器或发起付费推理。

## NOT TESTED — 明确未验证

Windows脚本/ACL/安装器；Docker构建启动；真实New API/LiteLLM连通与原生导出；真实付费模型评测；Codex/Claude Code/OpenCode实际运行；跨版本schema回滚；父站完整构建；长时间生产稳定性、海量数据性能、真实成本节省和付款转化。

## 已实现但当前测试未通过的功能

最终本地测试集中没有残留失败项。早期MODE变量冲突、DELETE空JSON头、E2E数据库清理时序问题已修复；依赖安全问题已升级。安装浏览器CDN下载的失败保留日志，并有可执行的替代二进制测试结果。未测的外部能力不能因此标PASS。

## 尚未实现

## 尚未验证的商业假设
