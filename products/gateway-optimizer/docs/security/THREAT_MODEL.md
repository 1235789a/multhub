# 基础威胁模型与安全边界

资产：供应商 API Key、管理令牌、用量元数据、费用账本与备份。主体：本地用户、同机其他用户、恶意网页、导入文件、供应商返回值、其他租户。边界：浏览器→core-api→SQLite；core-api→明确允许的 LiteLLM 模型清单。

| 风险 | 本次控制 | 验证与限制 |
|---|---|---|
| Key 泄漏 | 不收集前端供应商 Key；仅服务进程环境变量；不记录请求日志；通用错误；strict schema 拒绝凭据字段 | 单元/API 检查通过；真实供应商连接未测 |
| 越权 | local 模式至少32字符 bearer token，服务端绑定 tenant + admin/viewer；viewer 禁止写与备份 | API 跨租户、缺 token、角色测试通过；没有 SSO、MFA、密钥托管服务 |
| 恶意网页/CSRF/重绑定 | 只接受 localhost/127.0.0.1/::1 Host；拒绝异源 Origin；无 CORS；CSP 禁止外部脚本、内联脚本和 iframe | Host/Origin 测试通过；本地 OS 管理员可访问文件/进程环境 |
| SSRF | URL 只来自管理员进程环境，必须 HTTPS + 精确 origin 白名单；禁止 userinfo/query/hash/非根路径；仅公共 IPv4，DNS 检查并在建立连接时再次校验；禁止重定向 | 私网、元数据地址、IPv6、DNS私网解析测试通过；真实 DNS/公网供应商请求未测 |
| 配置注入/XSS/CSV 公式 | 不生成/执行用户命令；URL无前端输入；DOM textContent；标识符白名单；CSV 单元格防公式；不执行评测返回代码 | 代码检查与 schema 测试；不是完整渗透测试 |
| 重复收费/竞争 | tenant+request_id 数据库唯一键；WAL、busy timeout；批量事务；冲突拒绝 | 同进程、HTTP并发、4进程200次竞争通过 |
| 导入/资源耗尽 | 2MB body、CSV 10000行、每行50000字符、schema大小限制、每分钟500请求 | 基础限制；SQLite同步报表不适合大规模公网流量 |
| 导出泄漏 | 不保存正文/凭据；诊断只聚合；备份限 admin；文件权限私有 | 列级检查通过；metadata 仍可能是商业秘密 |
| 数据破坏 | 删除须 admin + 显式租户名；备份恢复验证、事务、租户绑定 | 单元与E2E备份/删除/恢复通过；无自动异地备份 |

默认 demo 是公开演示身份，仅可用于模拟数据；不要导入私人数据到 demo。真实数据使用 GATEWAY_MODE=local。访问令牌仅在页面内存使用，刷新后需重输；供应商凭据绝不返回浏览器。

SQLite 数据库不是静态加密库。个人模式需依赖操作系统账户权限和磁盘加密；Windows ACL 尚未验证，chmod 不能当成 Windows 安全承诺。备份没有内置加密，建议由用户放入自己的加密存储；不要将带真实元数据的备份提交 Git。删除租户会清除逻辑记录，不等同于取证级安全擦除；SQLite WAL、旧备份及磁盘快照可能保留旧页。彻底移除需停机后依照用户 OS 安全销毁整个专用数据目录及备份。

本地 bearer 配置是最小可行身份验证，不是生产 SaaS 身份体系。未完成生产安全审计，无公网部署/收费发布。
