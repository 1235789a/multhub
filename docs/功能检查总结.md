## 🔧 发现并修复的问题清单

### 问题 1: `scoring-rules.ts` 类型错误
**严重程度**: 🔴 高

**问题描述**:
`ScoringRule.dimension` 类型包含了 `total` 字段，但评分规则中不应该包含总分。

**修复方案**:
将类型从 `keyof OpportunityScore` 改为 `Exclude<keyof OpportunityScore, 'total'>`

**修复位置**:
- `/workspace/src/intel/data/scoring-rules.ts`:27
- `/workspace/src/intel/data/scoring-rules.ts`:33

---

### 问题 2: `geo-generator.ts` 未定义变量
**严重程度**: 🔴 高

**问题描述**:
`generateCaseStudies` 函数中使用了 `productName` 变量，但没有定义。

**修复方案**:
在函数开头添加变量定义：
```typescript
const productName = opportunity.productIdea.name.en;
const productNameZh = opportunity.productIdea.name.zh;
```

**修复位置**:
- `/workspace/src/intel/services/geo-generator.ts`:176-177
- 更新了 before/after 文案中的产品名称引用

---
