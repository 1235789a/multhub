## 1. 项目概览

### 1.1 项目定位

**Multhub** 是一个 AI 工具市场 + AI 机会引擎，目标是：
- 展示和销售 AI 工具
- 自动发现高价值产品机会
- 生成 GEO 内容获取自然流量
- 通过 USDT 收款形成商业闭环

### 1.2 核心功能

1. **产品展示与销售**
   - 工具商店展示产品
   - USDT/TRC20 支付收款
   - 试用管理和转化

2. **AI 机会引擎**
   - 自动发现产品机会
   - 6 维度评分系统
   - 从机会到产品的自动化生成

3. **GEO 内容系统**
   - 自动生成 FAQ、UseCase、Comparison、CaseStudy
   - 结构化数据（Schema.org）
   - SEO 友好的内容矩阵

```typescript
export async function POST(request: Request) {
  const { address } = await request.json();
  
  // 验证地址格式
  const isValid = isValidTRC20Address(address);
  const format = getAddressFormat(address);
  
  return Response.json({
    isValid,
    format,
  });
}

function isValidTRC20Address(address: string): boolean {
  // TRC20 地址以 "T" 开头，长度 34 位
  return /^T[A-HJ-NP-Za-km-z1-9]{33}$/.test(address);
}
```
