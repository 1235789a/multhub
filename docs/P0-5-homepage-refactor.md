# P0-5: 首页重构 - 聚焦3秒转化

## 概述

重构首页，让用户在3秒内理解：
1. 我遇到了什么问题
2. 这个工具解决什么
3. 免费试用
4. USDT购买

## 主要改动

### 1. 移除复杂动画

删除了原有的：
- 3D碎片动画
- 视差滚动效果
- 加载进度条
- 装饰性元素

### 2. Hero区域重新设计

**核心元素（从上到下）：**
- 主标题："独立开发者的 AI 工具工具箱"
- 副标题："发现机会 → 开发工具 → 获得收入"
- 三大卖点卡片：
  - 🚀 免费试用
  - 💰 USDT 支付
  - ♾️ 一次买断

### 3. 产品卡片优化

每个产品卡片包含：
- Emoji图标
- 产品名称
- 一句话介绍
- 价格（突出显示）
- 功能列表（3点）
- 双按钮：
  - 免费试用（绿色，突出）
  - 用USDT购买（灰色或黑色）

### 4. 问题-解决方案区块

左侧：😫 你遇到的问题
右侧：✅ 我们的解决方案

采用对比式设计，直观展示价值。

### 5. 只展示可用产品

过滤逻辑：
```typescript
const getAvailableProducts = () => {
  return PRODUCTS.filter(p => p.status === "available" || p.status === "beta");
};
```

## 设计原则

1. **简洁至上**：移除所有不必要的视觉元素
2. **直接转化**：每个卡片都有清晰的CTA
3. **3秒理解**：用户一眼就能看到问题、解决方案、价格
4. **USDT优先**：所有购买按钮都强调USDT支付
