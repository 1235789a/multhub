## Deliberate safety boundaries

- Product photos remain private unless a separate public URL is supplied for an approved passport.
- Admin access fails closed when Cloudflare Access is not configured in production.
- Transaction hashes are not treated as verified payments without human review.
- No sample product, case study, rank, citation, traffic, or sales result is presented as real.
- Publication of discovery products is a separate explicit checkbox after maker facts are checked.
