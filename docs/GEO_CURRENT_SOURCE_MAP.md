## Brand/entity collision

Public searches for `molthub` and `molthub Web3 GEO` surfaced a separate AI-agent compute project using the same or nearly identical name. Results included `moithub.com`, Medium, Level Up Coding, Reddit and other AI-agent ecosystem pages. The exact-domain query `"molthub.click"` did not return a molthub result in the observation.

This does not authorize a rebrand. It does mean off-site descriptions must consistently use the full entity string:

> molthub — Web3 GEO and AI-search visibility services at molthub.click

The domain, category and service should appear together wherever a legitimate profile allows it.

## Resulting content decisions

- Keep the homepage stable.
- Publish five evidence pages with distinct commercial, sector, technical, pricing and measurement intent.
- Use direct answers, fact tables, evidence grades, limitations, dates and visible sources.
- Treat stablecoin infrastructure as the strongest sector opportunity.
- Build entity disambiguation through consistent third-party profiles rather than more site-wide schema.
- Do not claim indexed-page counts without Search Console.
