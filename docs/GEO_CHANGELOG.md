# molthub GEO Changelog

## 2026-08-17 — Entity and evidence foundation

### Baseline

The site was a working Web3 GEO service website with public pricing, a free scan, account access, USDT-TRC20 checkout, sample-report structure and fifteen insight articles. The main gap was a lack of inspectable methodology, dated first-party research and a clear entity page.

### Primary problem

molthub explained what it sold more clearly than how its conclusions would be produced, measured and limited.

### Changes implemented

- Locked the public brand entity to `molthub` and `molthub.click`.
- Simplified the primary navigation and removed the duplicate Account link.
- Added an explicit sample-data badge to static report metrics.
- Removed unsupported daily-publishing promises.
- Clarified that the Windows installation is an installable web app.
- Added lazy loading and asynchronous decoding to editorial images.
- Converted fifteen insight covers from PNG to WebP.
- Replaced repeated homepage hero artwork in secondary sections with process/research visuals.

### Pages created

- `/about`
- `/methodology`
- `/research/self-geo-experiment`

### Technical changes

- Replaced the previous site-wide schema with an Organization, WebSite and ProfessionalService graph based on visible facts.
- Removed unsupported USD offers from the site-wide structured data.
- Added page-specific canonicals to core public routes.
- Added page-specific Open Graph and X metadata to insight detail pages.
- Added breadcrumb UI and BreadcrumbList structured data to key content pages.
- Marked account, checkout and sign-in routes `noindex`.
- Removed checkout from the sitemap and added About, Methodology, research and Partners.

### Evidence assets

- GEO baseline and diagnosis
- Forty-query buyer universe
- Citation-gap analysis
- Monitoring specification
- Off-site authority plan
- Public self-GEO experiment record

### Remaining gaps

- No measured non-brand AI visibility baseline has been completed.
- No Search Console index baseline is available in the repository.
- No permissioned public client outcome is published.
- Third-party authority remains limited.
- Automated article publishing is intentionally not claimed or implemented.

### Off-site work required

- Verify indexing and submit the updated sitemap in Google Search Console.
- Run and record the first repeated AI-query baseline.
- Build legitimate ecosystem and community references.
- Publish a real client outcome only with permission and dated evidence.

### Measurement plan

Use the five-query initial set weekly for eight weeks. Record platform, model when known, exact query, mention, citation, citation URL, factual accuracy, competitors and notes. Connect AI referral traffic and qualified conversions only after analytics can distinguish them.
